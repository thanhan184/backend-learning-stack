# Book Management API

## Features

- Author CRUD
- Category CRUD
- Book CRUD
- Book filtering
- Pagination
- Author - Book relationship
- Category - Book relationship

## Run locally

# Kích hoạt môi trường ảo
- "Windows": venv\Scripts\activate
# Chạy project
uvicorn app.main:app --reload

## API Documentation

http://localhost:8000/docs

## Database

SQLite for FastAPI demo
